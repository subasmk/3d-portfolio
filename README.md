# Subash MK — Drive My Portfolio

An interactive 3D portfolio inspired by Bruno Simon's famous drivable portfolio.
Don't read it — **drive it.**

**Live:** https://subasmk.github.io/3d-portfolio/

## What it is
A single-page Three.js world with a drivable car. Drive into a coloured zone to open it:
**About · Projects · Skills · Nientra · Contact** — with a HUD, speedometer, minimap,
building collisions, boost, jump and horn.

## Controls
- **W A S D / Arrows** — drive & steer
- **Shift** — boost · **Space** — brake · **R** — reset · **J** — jump · **H** — horn
- Mobile: on-screen buttons

## Tech
Three.js (WebGL) in one self-contained `index.html`. No build step — open it or host it anywhere static.
